智融行者 ROS2 项目——验收人员一键部署说明

适用电脑：
1. 64 位 Windows 11（推荐）或 Windows 10 2004 以上。
2. 可以连接互联网，系统盘建议至少保留 25 GB 空间。
3. 当前 Windows 账号有管理员权限。
4. 显卡与显示器型号不限；首次部署推荐在电脑本地操作，不要远程控制。

操作方法：
1. 完整解压“智融行者验收一键部署.zip”。
2. 双击“一键部署并打开验收.cmd”。
3. Windows 弹出管理员权限（UAC）时点击“是”。
4. 首次安装 WSL 时若提示重启，点击“是”；重新登录后安装器会自动继续。
5. 等待安装器完成 Git、Python、WSL2、Ubuntu 22.04、ROS2、Gazebo、Nav2、
   项目依赖和源码构建。根据网络速度，首次部署通常需要 20～60 分钟。
6. 部署完成后会自动打开验收面板，并启动 Gazebo、RViz 和 Nav2。
7. 等状态显示“完整仿真已就绪”，再逐项点击“开始验收”。

自动安装位置：
- Windows 源码：文档\ZhirongXingzhe
- Linux 工作空间：$HOME/zhirong_xingzhe_ws
- 部署日志：%LOCALAPPDATA%\ZhirongXingzhe\bootstrap.log

注意事项：
- 不要在部署过程中关闭窗口、断网或强制关机。
- WSL2 是本项目运行 ROS2/Gazebo 所需的轻量 Linux 环境，安装器会自动配置。
- 如果网络、Windows Update、公司安全策略或虚拟化设置阻止安装，脚本会停止并保留日志；
  修复问题后重新双击部署入口即可继续，不会覆盖未提交的源码修改。
- 本部署包只控制仿真机器人，不会驱动真实电机或实体设备。
