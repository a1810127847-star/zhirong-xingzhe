# PPO 避障扩展实验方案

PPO 属于计划书中的三级研究扩展，不作为基础/完整功能验收前置条件。
当前稳定基线是 Nav2 NavFn + DWB + Collision Monitor。

## 实验目标

比较 PPO 局部避障策略与 DWB 在相同动态场景中的：

- 任务成功率
- 到达时间
- 路径长度
- 最小避障距离
- 急停次数
- 控制平滑度

## 状态空间

- 前方 180° LiDAR 下采样为 60 维
- 目标在机器人坐标系中的距离和方位角
- 当前线速度、角速度
- 上一时刻动作

## 动作空间

连续动作：

```text
linear.x ∈ [0.0, 0.30] m/s
angular.z ∈ [-0.60, 0.60] rad/s
```

PPO 网络输出使用对称归一化动作 `[-1, 1]²`，环境再映射到以上物理范围。
角速度上限与当前冻结的 DWB 基线一致，避免 PPO 通过更高速度获得不公平优势。

无论策略输出什么，最终仍必须经过 `/cmd_vel → Collision Monitor →
/cmd_vel_safe`，PPO 不得绕过安全层。

## 奖励建议

```text
+ 目标距离减少
+ 成功到达
- 碰撞
- 与障碍过近
- 超时
- 角速度突变
- 原地振荡
```

## 训练场景

1. 空场点到点。
2. 单静态障碍。
3. 双静态障碍。
4. 单动态障碍横穿。
5. 障碍随机出生位置和速度。

每轮随机化起点、终点和障碍位置，训练环境使用无 GUI Gazebo。

## 公平对比

- 使用同一机器人模型、地图、传感器噪声和最大速度。
- 每种策略至少运行 30 次固定随机种子测试。
- DWB 参数冻结，不针对单个场景临时调参。
- PPO 模型、训练配置、随机种子和学习曲线必须保存。

## 完成标准

若 PPO 未在成功率和安全距离上达到 DWB 基线，应如实报告为实验结果，
不得替换当前稳定导航控制器。项目现有测试脚本可以复用来采集目标误差、
最小距离和成功率。

## 已落地实现

- ROS2 包：`ros2_ws/src/zhirong_ppo`
- 训练专用世界：Gazebo + 四轮底盘 + 独立 Collision Monitor，不启动 Nav2
- 环境检查：`ros2_ws/tools/run_ppo_smoke.sh`
- 训练入口：`ros2_ws/tools/run_ppo_training.sh`
- 独立评估：`ros2_ws/tools/run_ppo_evaluation.sh`
- 训练产物：`artifacts/ppo/<运行编号>/`

每次训练保存：

- `config.json`：依赖版本、随机种子、课程和超参数
- `monitor.csv`：逐回合成功、碰撞、路径、安全距离和控制平滑度
- `progress.csv`：PPO 学习曲线和优化指标
- `ppo_zhirong.zip`：可重新加载的模型
- `checkpoints/`：默认每 `256` 环境步保存的可恢复模型
- `evaluation.json`：训练后确定性评估

## 首轮工程验证

2026-08-15 使用空场课程、随机目标、随机初始朝向完成 `1024` 步短训练：

- Gymnasium 环境检查：通过
- 观测形状：`(66,)`
- 单障碍课程冒烟：通过
- 模型保存后新进程重新加载：通过
- 3 轮确定性评估：成功率 `33.3%`
- 碰撞率：`0%`
- 平均最小雷达距离：`0.358 m`
- 平均 Collision Monitor 干预：`22` 次/回合

这组样本只作为训练链路验收。它尚未达到稳定 DWB 的交付标准，也不能作为
算法优劣结论。下一研究阶段是延长空场训练、迁移到单障碍/动态障碍课程，
最后执行双方各 30 个固定种子的冻结参数测试。

## 课程训练进展（2026-08-15）

训练环境现支持四级课程：

1. `straight`：固定正前方目标。
2. `fan`：右、左、小右、小左、正前方严格循环。
3. `empty`：随机目标和初始偏角。
4. `single`：随机目标和单障碍。

后续已完成新版方位观测从零训练和 Reward V4 对称转向整形：

- 直行课程：`10/10`，碰撞 `0/10`
- 固定扇形正式 30 回合：`24/30`（`80%`），碰撞 `0/30`
- 随机空场最佳检查点正式 30 回合：`21/30`（`70%`），碰撞 `0/30`

随机空场未达到 `80%` 课程晋级门槛，因此本轮不进入单障碍正式训练，也不
替换 DWB。完整实验、检查点选择和方向偏置分析见
`docs/PPO_TRAINING_REPORT_2026-08-15.md`。
