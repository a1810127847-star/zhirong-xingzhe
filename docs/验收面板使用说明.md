# 智融行者项目验收面板

## 启动

双击项目根目录的 `打开项目验收面板.vbs`。该入口使用 `pythonw.exe`，不会额外弹出终端窗口。

如果 `.vbs` 被系统策略阻止，可以双击 `打开项目验收面板.cmd` 作为备用入口。

## 推荐顺序

1. 点击“启动完整仿真”，等待状态变为“完整仿真已就绪”。
2. 确认 Gazebo 和 RViz 可见。
3. 依次点击“点到点导航”“动态避障”“多点巡航”的“开始验收”。
4. 每项完成后查看卡片上的“合格/失败”和下方运行记录。
5. 固定项目都合格后，可点击“开始随机验收”检查路线变化时的鲁棒性。

同一时间只允许运行一项验收，避免多个测试同时向机器人发送导航目标。

点到点导航会先回原点、测量 `0.8 m` 直线路段，再自动返回原点；动态避障验收也会先确认机器人回到原点，从而保证障碍物确实位于测试路径上。

## 紧急停止

点击“紧急停止”会：

- 中止面板当前运行的验收进程；
- 请求取消 `/navigate_to_pose` 的活动目标；
- 向任务管理器发送 `cancel`；
- 持续 1.5 秒发布零速度。

该按钮只作用于当前仿真机器人，不控制实体硬件。

## 远程控制看不到 Gazebo/RViz

若 Windows 任务栏中存在 Gazebo/RViz，但远程画面不可见，可点击“远程黑屏修复”。该操作会执行 `wsl --shutdown`，因此会停止所有 WSL 发行版中的进程，包括 Docker。面板会在执行前再次确认。

重置后重新点击“启动完整仿真”。

## 自动判定的合格标准

### 1. 点到点导航

- Nav2 导航返回 `SUCCEEDED`，测试结束后能自动返回原点。
- 实际轨迹最大横向偏差不超过 `0.08 m`，实际路程/直线距离不超过 `1.12`。
- 安全速度到里程计响应不超过 `0.40 s`，移动中的转向正负反复不超过 4 次。

### 2. 动态避障

- 成功到达目标点，位置误差不超过 `0.30 m`。
- 机器人与动态障碍物中心的最近距离不小于 `0.40 m`。
- 观察到横向绕行距离不少于 `0.12 m`，或至少发生 3 次安全降速干预。
- 至少接收到 1 条 Nav2 全局规划，并在测试后成功返回原点。

### 3. 多点巡航

- 按 `east → northeast → north → home` 顺序完成 4 个航点，期间没有任务失败。
- 每个航点进入 `0.30 m` 区域后开始采样，并在该点被任务管理器确认完成时立即封存；转向方向反复次数必须为 `0`，无效往返转角不超过 `0.12 rad`。这样不会把下一段路线的正常转向误算到上一个点。
- 任务结束后活动任务为空、等待队列为空。
- 最终回到原点，位置误差不超过 `0.30 m`。

### 4. 随机鲁棒巡航

- 每次自动生成 5 条闭环路线，每条包含 3 个随机航点和原点。
- 航点在地图中央安全区域内随机改变方向和半径，并同时覆盖顺时针、逆时针可能性。
- 每条路线沿用多点巡航的硬标准：航点 `0.30 m` 区域内转向反复次数为 `0`，无效往返转角不超过 `0.12 rad`，回原点误差不超过 `0.30 m`。
- 只有 5 条路线全部通过，面板才显示“合格”。运行记录会打印 `RANDOM_PATROL_SEED`；若失败，可用同一个 seed 精确复现，不会因下一次随机路线改变而丢失问题。

固定路线仍用于正式、可重复的基准验收；随机路线是额外的鲁棒性压力测试，不能代替固定验收。

当前开发回归记录：种子 `1025773903` 与 `3316381630` 各 `5/5` 通过，累计 `10/10` 条路线、`40/40` 个到点合格；最大无效往返转角 `0.0564 rad`，最大回原点误差 `0.179 m`。

在 WSL 中手动复现某次随机验收：

```bash
python3 /mnt/c/Users/legend/Documents/暑期项目/ros2_ws/tools/validate_random_patrol.py \
  --cases 5 --seed <面板输出的随机种子>
```

## 结果标志

- 点到点导航：`NAVIGATION_VALIDATION_OK`
- 动态避障：`DYNAMIC_AVOIDANCE_VALIDATION_OK`
- 多点巡航：`TASK_PATROL_VALIDATION_OK`
- 随机鲁棒巡航：`RANDOM_PATROL_VALIDATION_OK`

面板只有在测试进程正常退出且检测到对应标志时才显示“合格”。
